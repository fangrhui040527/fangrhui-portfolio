# fangrhui-portfolio

Personal portfolio for **Foo Fang Rhui** — AI Software & Automation Engineer.

A single self-contained `index.html`: no build step, no dependencies, no
runtime JavaScript beyond the page's own. Fonts load from Google Fonts; the
portrait is embedded directly in the file.

## Run locally

Open `index.html` in a browser, or serve it:

```bash
npx serve .
```

## Deploy

Static site — no framework, no build command, no environment variables.
